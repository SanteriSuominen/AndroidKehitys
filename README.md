# AndroidKehitys

Android-kehityksen kurssin tehtävät ja palautukset.

Tehtävät on järjestetty tekniikan, viikon ja tehtävän mukaan. Kotlin-, React Native- ja Flutter-tehtävät saavat omat kansionsa tässä repositoriossa.

## Rakenne

```text
AndroidKehitys/
├── Kotlin/
├── React/
│   └── Viikko1/
│       └── Kotitehtavat/
│           └── Osa2/    # LaskuriSovellus (React Native + Expo)
└── Flutter/
```

## Palautukset

| Tekniikka | Viikko | Tehtävä | Sovellus |
| --- | --- | --- | --- |
| React Native | 1 | Kotitehtävät, osa 2 | [LaskuriSovellus](React/Viikko1/Kotitehtavat/Osa2/) |

Lisää tulevat tehtävät vastaavan tekniikan alle esimerkiksi polkuun `Kotlin/Viikko2/Kotitehtavat/Osa1/`.
