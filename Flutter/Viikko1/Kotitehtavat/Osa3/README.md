# LaskuriSovellus — Flutter

Android-kehityksen kurssi: viikko 1, kotitehtävät, osa 3.

Laskuri rakennetaan vaiheittain Jetpack Compose -osaamisen pohjalta. Aloituspohja näyttää vain tekstin; laskurin toiminnallisuus lisätään harjoituksissa.

## Käynnistys

Avaa tämä kansio Android Studiossa Flutter- ja Dart-lisäosien kanssa tai käytä terminaalia:

```bash
flutter pub get
flutter devices
flutter run
```

Valitse yhdistetty Android-puhelin. Flutter asentaa sovelluksen laitteelle, Expo Goa ei tarvita. Ensimmäinen Android-käännös voi kestää useita minuutteja.

## Ensimmäinen harjoitus

Avaa `lib/main.dart` ja vaihda `Text('Hello World!')` muotoon `Text('Laskuri')`.

Pidä `flutter run` käynnissä. Tallenna muutos ja paina terminaalissa `r` (hot reload).

## Tarkistus

```bash
flutter analyze
```
